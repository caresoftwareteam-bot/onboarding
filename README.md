# CARE Software Team Onboarding

## ภาพรวม

Repository นี้จัดทำขึ้นเพื่อใช้เป็นศูนย์กลางเอกสารสำหรับนักศึกษาฝึกงาน สมาชิกใหม่ และผู้ที่เข้าร่วมโครงการพัฒนาซอฟต์แวร์ภายในทีม

เป้าหมายของเอกสารชุดนี้คือการเตรียมความพร้อมด้าน

* Software Development Process
* Git Workflow
* Documentation
* Team Collaboration
* Responsible AI Usage
* Engineering Mindset

เอกสารทั้งหมดถูกจัดทำขึ้นเพื่อสร้างพื้นฐานร่วมกันก่อนเริ่มปฏิบัติงานจริง ทั้งในด้านเทคนิค กระบวนการพัฒนา และการทำงานร่วมกับผู้อื่น

# เอกสาร

## Git Handbook

เอกสารมาตรฐานสำหรับการใช้งาน Git ภายในทีม

เนื้อหาประกอบด้วย

* Git Basics
* Branch Management
* Commit Message Standard
* Pull Request Workflow
* Release Workflow

ไฟล์:

```text
GIT_HANDBOOK.md
```

---

## AI Guideline

แนวทางการใช้ AI เพื่อสนับสนุนการพัฒนาซอฟต์แวร์อย่างมีความรับผิดชอบ

เนื้อหาประกอบด้วย

* AI Tools ที่อนุญาต
* แนวทางการใช้งาน
* ข้อควรระวัง
* ความรับผิดชอบของผู้ใช้งาน
* หลักเกณฑ์การประเมิน

ไฟล์:

```text
AI_GUIDELINE.md
```

# สำหรับนักศึกษาฝึกงาน

ก่อนเริ่มโครงการ กรุณาศึกษาเอกสารตามลำดับดังนี้

1. Git Handbook
2. AI Guideline
3. Internship Guide
4. Evaluation Guide

หลังจากศึกษาเอกสารครบแล้ว ให้ Clone Repository ของโครงการที่ได้รับมอบหมายและเริ่มดำเนินงานตาม Sprint Plan

# หลักการสำคัญ

การประเมินจะพิจารณาจาก

* ความรับผิดชอบ
* การทำงานร่วมกับทีม
* การสื่อสาร
* การแก้ปัญหา
* การเรียนรู้และพัฒนาตนเอง
* ผลลัพธ์ของงาน

การใช้ AI สามารถทำได้ แต่ผู้พัฒนาต้องสามารถอธิบายสิ่งที่ตนเองส่งมอบได้
